## 🎯 How to use the workflow

The interface shows a dashboard for your active projects. You can organize files, create task lists, and track progress for each stage of your engineering or research work.

### Setting up a project
Open the file menu and select "New Project." Give your project a title and select a folder. This folder stores your work. The software creates a structure to help you categorize your notes, data files, and AI interaction logs.

### Breaking down tasks
The software features a task decomposition tool. Enter your main goal, such as "Write a research paper on machine learning." The AI helper splits this into smaller items like "Gather data sources," "Draft outline," and "Review bibliography." You can edit these items or add your own.

### Using AI tools
Connect your API key in the settings menu to enable advanced assists. Once setup is complete, you can click the "Analyze" button on any task. The software reviews your current documents and suggests next steps. It helps you draft content or check for errors in your code.
