# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-07-21

### Added

- Initial public release of `ai-engineering-workflow`.
- Issue creation, breakdown, execution, update, status, and closure modes.
- Atomic task execution and verification requirements.
- Reusable issue, architecture, task, status, and close-report templates.
- Detailed workflow reference guides.
- Local validation example.
- Installation and usage documentation.
- MIT License.

### Changed

- Replaced repository-root resource paths in `SKILL.md` with portable Skill-relative paths.
- Added explicit reference-loading rules for every workflow mode.
- Reduced `SKILL.md` below 500 lines while preserving the core workflow rules.
- Added an `issue-update` regression scenario and marked it pending a fresh Codex runtime test.
- Clarified project-level and user-level installation instructions.
- Unified status casing and repository structure documentation.
